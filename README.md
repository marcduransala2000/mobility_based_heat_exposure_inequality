# mobility_based_heat_exposure_inequality

Repository for the results of the paper **“Mobility shapes heat exposure inequalities in cities”**

## Structure

- `src/`             – Main code for data processing, analysis and modelling  
- `datasets/`  – Generated CSV dataframes
- `README.md`        – This file

## Data availability

Mobility data for July–August 2022 and 2023 were obtained from the Spanish Ministry of Transport open data portal:  
<https://www.transportes.gob.es/ministerio/proyectos-singulares/estudios-de-movilidad-con-big-data/opendata-movilidad>

Demographic and socioeconomic attributes (median income, population) were obtained from the Spanish National Statistical Office (INE):
<https://www.ine.es>


Only the processed daily mobility data for **Madrid** are included as an illustrative example
